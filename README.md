# 대구로 로컬푸드 연결 (시연용 MVP)

대구·경산 생활권별 로컬푸드 장보기와 공급자 주문 처리를 한 브라우저에서 시연하는 React + TypeScript 웹 앱입니다.
모든 가게·사람·가격·쿠폰·잔액은 **가상 자료**이고, 결제·충전은 **모의 처리**합니다. 외부 API·DB·API 키가 필요 없습니다.

## 화면
홈(생활권) → 상품 상세 → 장바구니(주문 확인) → 주문내역 → 공급자 관리, 그리고 홈의 가게별 보기.

## 완료 기준 시연 순서
1. **시장 반찬 픽업**: 대구에서 반찬 3종 세트 담기 → 장바구니에서 날짜·시간 선택(추천 쿠폰 −2,400원, 총 9,600원) → 주문 → 공급자 탭에서 ‘주문 수락’ → 진행 중 탭에서 ‘준비 완료’ → 주문내역에 픽업 안내
2. **생활권 변경**: 반찬을 담은 채 경산으로 바꾸면 안내가 뜨고 장바구니는 그대로 남음
3. **품절**: 사과즙은 처음부터 품절, 공급자 탭에서 다른 상품도 품절 처리 가능
4. **잔액 부족**: 대구에서 부사 사과(배송비 포함 27,000원)를 가상 대구 지역화폐(22,000원)로 결제하면 주문이 멈춤
5. **주문 취소**: 접수 상태 취소는 재고·잔액·쿠폰을 한 번만 복원, 준비 중이면 ‘문의 접수’로 남음

⋯ 메뉴 → ‘데모 초기화’로 언제든 처음 상태로 돌아갈 수 있습니다.

## 파일 구성
| 파일 | 내용 |
|---|---|
| `index.html`, `index.tsx` | 진입점 |
| `src/App.tsx` | 헤더·하단 탭·화면 전환·확인 시트·알림 |
| `src/screens.tsx` | 홈, 가게, 상품 상세, 장바구니, 주문내역, 공급자 화면 |
| `src/store.tsx` | 앱 상태와 버튼 동작, localStorage 저장(안 되면 메모리 모드) |
| `src/logic.ts` | 시연 자료 생성, 쿠폰 추천·금액 계산, 취소 복원 규칙 |
| `src/data.ts` | 타입과 고정 시연 자료(판매처 6, 상품 15, 쿠폰 4) |
| `src/art.tsx` | 직접 그린 SVG 일러스트와 아이콘 |
| `src/index.css` | 색·글꼴 토큰과 화면 스타일(다크모드 포함) |

## 내 컴퓨터에서 실행
```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # 타입 검사 + 배포용 빌드
```
